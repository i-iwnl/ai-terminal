## 2. 着手前に実コードで測り直した結果（2026-08-03）

**Issue 本文の前提が2つ古くなっていた。** loop.md「計画書の現状認識は古くなる」の9件目・10件目。

| Issue 本文の記述 | 実際 |
|---|---|
| 「`README.md` のショートカット表に `Cmd+E` / `Cmd+J` / `Cmd+Shift+J` / `Cmd+Shift+[` / `Cmd+Shift+]` が1つも載っていない」 | **全部載っている**（README の該当表に5件とも実在）。**この作業項目は既に不要** |
| （A-4 の前提）「`Cmd+W` にタブを閉じる手段が無い」 | `Cmd+W` は `close-pane` だが、**README が「タブに残るペインが1枚だけならタブごと閉じる」と明記**しており、意味変更は意図的に文書化済み。**問題は「分割中のタブを1手で閉じられない」ことだけ**に絞られる |

依然として正しい前提:

- `menu.ts` の `role: 'resetZoom' / 'zoomIn' / 'zoomOut'` は実在し、**`registerAccelerator` が true**（`actionItem()` を通らないため）
- **zoom 3種は README に1つも載っていない**
- `close-tab` は `accelerator: undefined`
- `Cmd+E` は `last-active-tab`（`shortcuts.ts`）
