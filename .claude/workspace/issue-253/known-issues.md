## 1. 手動で起動した gemini は、原理的に一覧へ出せない

### 症状

ai-terminal のシェルタブで `gemini` を手で起動しても、サイドバーの一覧に出てこない。

### 原因

一覧の claude 側の情報源は `claude agents --json` で、これは gemini を知らない。
アプリが gemini を追える経路は `listLiveAgentSessions()`（自前で作った tmux セッションの
一覧）だけで、**アプリが起動していない gemini プロセスには手がかりが無い**。

### 影響範囲

- サイドバーの「このマシン全体の AI」（gemini は claude と同じ土俵に並ばない）

### 対処方針

- [ ] 対処しない（Issue #253 の非目標として明記済み）。必要になったら
      「`gemini` プロセスを `ps` で拾う」等の別手段を独立した Issue で検討する

### 優先度

P3

### ステータス

未対処（意図的な非目標）

## 2. `~/.claude/sessions/` に、死んだプロセスの `.key` が残る

### 症状

原因調査中に起動・終了した claude の `<pid>.<hash>.key` が `~/.claude/sessions/` に残った
（`.json` は `claude agents --json` 側が生存 pid で濾しているので一覧には出ない）。

### 原因

CLI 側の後始末。ai-terminal の責任範囲外。

### 影響範囲

- なし（アプリの表示には影響しない）

### 対処方針

- [ ] 対処しない。CLI 側の挙動として記録するに留める

### 優先度

P3

### ステータス

未対処（アプリ側の対処対象外）
