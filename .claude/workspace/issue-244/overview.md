# Issue #244 タブを閉じても AI が終了せず、アプリ側に終わらせる手段が無い（「閉じる」の意味を直す） - Overview

> **Issue**: [#244 タブを閉じても AI が終了せず、アプリ側に終わらせる手段が無い（「閉じる」の意味を直す）](https://github.com/i-iwnl/ai-terminal/issues/244)
>
> `useTmux: true`（出荷時の既定）でタブを閉じても、`pty.kill()` が殺すのは tmux クライアントだけで
> 内側の `claude` / `gemini` は生き残る。アプリ側に終了させる手段が1つも無いため、閉じるたびに
> プロセスが1本ずつ累積する（実機で7本を観測）。「閉じる」という操作の意味そのものを直す。
>
> 詳細は以下の3ドキュメントに分割:
>
> - `architecture.md` - 触る構造・Contract変更・設計判断
> - `worklog.md` - 時系列の作業ログ・次に再開するとき最初に読むべきこと
> - `known-issues.md` - 判明した問題・未解決事項・先送りしたもの
>
> **最終更新**: 2026-08-09（周1+2 完了・code-review 是正済み）

## 1. ゴール

**「タブを閉じる」= 終了する / 「アプリを閉じる」= 生き残る** に意味を変える。あわせて、タスク一覧から
セッションを終了できる導線と、押せる/押せない行の理由を画面に出す。

tmux 永続化そのものは残す（Issue 側で「削除は解ではない」ことが 2026-08-09 に実測確認済み）。
