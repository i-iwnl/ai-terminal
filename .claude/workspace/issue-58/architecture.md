## 1. 対象トラック

main（PTY プロセスの cwd 観測）+ renderer（タブ単位の cwd 保持と追従）の2トラック。

| コンポーネント | 変更内容 | 影響範囲 |
|---|---|---|
| `src/main/pty/cwd.ts` | 追加（PID から cwd を読む。lsof の出力パースは純粋関数に切り出す） | manager の `pty:cwd` ハンドラ |
| `src/main/pty/manager.ts` | 変更（`pty:cwd` ハンドラ追加。PtyEntry に pid を持たせる） | preload / renderer |
| `src/main/app-paths.ts` | 変更（`resolveLaunchCwd()` を追加。`/` と空文字をホームへ倒す） | 履歴のパス導出・タスク絞り込みの初期値 |
| `src/main/agents/poller.ts` | 変更（`lastKnownCwd` の初期値を `getAppPaths().cwd` に） | タスク一覧の絞り込み |

## 2. Contract（src/shared/ipc.ts）変更

| チャンネル / 型 | 変更 | 内容 |
|---|---|---|
| `IpcInvoke.ptyCwd`（`pty:cwd`） | ADD | ptyId を渡すと、その PTY プロセスの現在の作業ディレクトリを返す。取得できなければ `undefined` |
| `RendererApi.pty.cwd` | ADD | `cwd(ptyId: string): Promise<string \| undefined>` |

`AppPaths` の型は変えていない。**値の意味だけが変わった**（`cwd` は「アプリを起動したディレクトリ」から「アプリを起動したディレクトリ、ただし Finder 起動で `/` になる場合はホーム」になった）。型に現れない変更なので、`app-paths.ts` のコメントに明記してある。

## 3. 技術的制約・前提条件

- **PTY の出力は加工しない**（ルート CLAUDE.md の鉄則2）。cwd の追跡に OSC 7 を採らなかった理由の半分はここにある（詳細は設計判断履歴）。
- **Renderer は OS を直接触らない**（鉄則1）。プロセスの cwd を読むのは Main のみ。
- `lsof` は macOS に標準で入っている（`/usr/sbin/lsof`）。E2E の隔離ハーネスが残す最小 PATH（`/usr/bin:/bin:/usr/sbin:/sbin`）にも含まれる。
- 取得に失敗しても**直前の値を維持する**（外部コマンドの失敗でアプリの状態を壊さない。鉄則5と同じ方針）。

## 4. 設計判断履歴

| 日付 | 判断 | 根拠 | 代替案 |
|---|---|---|---|
| 2026-07-29 | **cwd はタブ単位で持つ。** `TabState.cwd` が唯一の正で、アプリ共通の「アクティブ cwd」はアクティブなタブの cwd の写しにすぎない | 主用途が「別々のリポジトリで claude を並走させる」である以上、全タブ共通の値では原理的に足りない。サイドバーは「いま見ているタブの文脈」を出すのが自然 | 全タブ共通のまま、明示的なディレクトリ選択 UI を足す案。手数が増えるだけで、`cd` した直後に開く動作が最短にならない |
| 2026-07-29 | **`cd` の追跡は PTY プロセスの cwd を Main が観測する**（macOS: `lsof -a -d cwd -p <pid> -Fn`）。ポーリングはアクティブなシェルタブ1本だけ、2秒間隔 | シェル側の設定に一切依存せず、どのシェルでも同じ挙動になる。`cd` だけでなく `pushd` / サブシェル / スクリプト経由の移動もすべて拾える | **OSC 7 を読む案は却下。** macOS 既定の zsh は OSC 7 を出さない（Apple_Terminal のときだけ `/etc/zshrc_Apple_Terminal` が出す）ため、こちらでシェル統合を注入しないと動かない。ユーザーの `.zshrc` を書き換えるのも、PTY の出力を横取りして解釈するのも避けたい |
| 2026-07-29 | **ポーリング対象はアクティブなタブ1本、かつ `kind === 'shell'` のみ** | 非アクティブなタブの cwd は誰も見ていない。エージェントタブは `cd` しない（tmux でラップされている場合、`lsof` が返すのは tmux クライアントの cwd で意味が無い） | 全タブを毎回見る案。タブ枚数に比例して `lsof` の起動が増える |
| 2026-07-29 | **Finder 起動のフォールバックは「ホームへ倒す」だけにする。最後に使ったディレクトリの永続化はしない** | `/` は `~/.claude/projects` の命名規則上どのディレクトリにも当たらないため、**確実に空**になる。ホームなら当たる可能性があり、当たらなくても `cd` すれば追従するようになった | 最後に使ったディレクトリを保存して復元する案。cwd が追跡されるようになった今、効くのは「起動直後の1枚目のシェルタブ」だけに縮小したので、必要になってから入れる |
