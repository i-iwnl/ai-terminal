## 1. ゴール

`useTabs.ts` の「タブ = PTY 1本」のフラットなモデルを「タブ = ペインの二分木」に置き換え、
分割・フォーカス・リサイズ・閉じるの4操作をキーボードとメニューから行えるようにする。

## 2. 完成条件

- [ ] Cmd+D で現在のペインを左右に分割し、新しいシェルの PTY が右に立つ
- [ ] Cmd+Shift+D で上下に分割する
- [ ] 分割後のペインをさらに分割できる（二分木。深さに制限なし）
- [ ] アクティブなペインが視覚的に区別でき、キー入力・Cmd+F / Cmd+K がそのペインに向かう
- [ ] ペインをクリックするとアクティブが移る
- [ ] Cmd+W はアクティブペインを閉じる。タブ内の最後の1枚だったときだけタブを閉じる
- [ ] ペイン境界をドラッグしてサイズを変更でき、xterm の cols/rows と PTY の resize が追従する
- [ ] Cmd+Option+矢印でペイン間をフォーカス移動できる
- [ ] メニューに分割の項目があり、キーが表示されている
- [ ] レイアウトツリーの操作（分割・閉じる・隣接ペイン探索）が純粋関数として `test/unit/` で検証されている
- [ ] E2E で「分割すると2つのターミナルが同時に見える」「片方を閉じると残りが全面になる」が検証されている
- [ ] README とスクリーンショットが分割表示を反映している
- [ ] 型チェック通過（`make check`）
- [ ] Lintチェック通過（`make check`）
