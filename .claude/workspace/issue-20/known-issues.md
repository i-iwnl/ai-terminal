## 1. cwd がアプリ起動時に固定され、複数リポジトリの並走が成立しない -> #58 として起票済み

      -> [#58](https://github.com/i-iwnl/ai-terminal/issues/58) として 2026-07-29 に起票
- [ ] #58 で方針を決める（タブ単位で持つか / `cd` を追跡するか / Finder 起動時のフォールバック）
- [ ] **#20 の PR 8・10・13 は #58 の決着後に着手する**（cwd を画面に出す提案なので、
      全タブ同一・起動時固定のままでは出しても情報量がない）

## 4. タブの閉じるボタンの当たり判定が、タブ選択の領域に張り出す -> #89 として起票済み

### 症状

PR 6（Target Size 24x24）でタブの閉じるボタンの当たり判定を 24x24 に広げた結果、
見た目 11x14 のボタンの左右に約 6.5px ずつ透明な当たり判定がはみ出す。
**その帯を押すと「タブを選択」ではなく「タブを閉じる」になる。**

### 原因（判明している場合）

タブの閉じるボタンは隣に別のボタンを持たないが、**タブそのものがクリック対象**（選択）。
「隣接するボタンと重ならない」だけでは足りず、**親要素がクリック対象である場合も考慮が要る**。
PR 6 の設計時点ではここを見落としていた（`design-rules.md` の記述も「閉じるボタン類は透明な当たり判定で広げる」までしか書いていない）。

### 影響範囲

- タブバー（`.tab-bar__tab` / `.tab-bar__close`）
- **誤爆の結果が破壊的**（タブを閉じると走行中のエージェントを見失う）。ただし claude は #60 の修正で履歴から resume すれば tmux セッションに戻れるようになった

### 対処方針

- [ ] PR 8 以降でタブバーを触るときに、次のどれを採るか判断する
  - タブの閉じるボタンだけ**縦方向にしか広げない**（横は現状のまま。WCAG の spacing 例外の考え方に寄せる）
  - タブ自体の高さを上げ、閉じるボタンの実寸を 24x24 にする（見た目が変わるので `/design-review` の対象）
  - 現状のまま許容する（**押し間違いの実測を先に取る**）
- [ ] 判断した結果を `design-rules.md` に「当たり判定を広げるときは、親がクリック対象かも見る」として一般化する

### 優先度

P2

### ステータス

**未対処。PR 10（#88）で評価だけ行い、修正しないと判断した。**

閉じるボタンをリーディング側（左）へ移し、選択中とホバー中のタブにだけ出すようにしたが、
**主要な誤クリック経路は変わらない**。CSS の `:hover` は、クリックする時点で必ず true に
なっている（ポインタがそのタブの上に無ければクリックできない）ので、**当たり判定は
まさに問題になる瞬間に有効化されている**。改善したのは背景タブの常時露出だけ。

張り出しの量そのものも不変（`::before` の `max(100%, var(--target-size-min))` は
そのまま）。張り出す向きが右から左へ変わっただけ。

**次にタブバーを触る PR で、記録済みの3案から選んで決着させること。**

## 5. S12 のスクリーンショットが「待たせている時間」を示せない（E2E ハーネスに動的フィクスチャが無い）

### 症状

PR 8（#82）で「あなたの番」の行に「3分0秒待たせています」を出せるようにしたが、
**README で配布している `docs/images/S12-task-list.png` には依然「75時間0分」が写っている。**
PR 8 が消そうとした「セッション起動からの通算」そのものである。

### 原因

`AgentTask.yourTurnSince` は `poller.ts` が **busy -> 非busy の遷移を観測した瞬間**にだけ埋まる。
E2E ハーネス（`e2e/fixtures/harness.ts`）の偽 CLI は**固定の `agents.json` を返し続ける**ので、
遷移が一度も起きず `yourTurnSince` は常に undefined になる。
表示はセッション起動からの通算へ縮退する（**これ自体は仕様どおりの正しい挙動**）。

結果として、E2E も スクリーンショットも新機能が効いている側を一度も通らない。
遷移検知そのものは `test/unit/your-turn-since.test.ts`（純粋関数 `computeYourTurnSince`）が
7件固定しているので、ロジックが無検証なわけではない。**足りないのは結合と、配布物の説得力。**

### 対処方針

- [ ] `harness.ts` に「ポーリング間で内容が変わる `agents.json`」を返す偽 CLI のモードを足す
- [ ] S12 で遷移を作り、「待たせている時間」が出た状態を撮り直す + E2E で文言を検証する

**同種の動的フィクスチャは Issue #56 の PR 7 でも要求されている**
（スプリッタのドラッグ中に `pty:resize` が飛ばず `mouseup` 後に1回だけ、を回数で数える）。
ハーネスの機能追加として独立に価値があるので、**PR 8 に混ぜず別 Issue として切り出す**判断をした。

### 優先度

P2

### ステータス

未対処（PR 8 のレビューで検出。**機能は動いているが、テストと配布画像がそれを示せていない**）

## 6. プロバイダの色相は、色覚特性を持つ晴眼のユーザーには常時は届かない

### 症状

PR 10（#88）で、タブのプロバイダ（claude / gemini / シェル）をタブ上端 2px の色相
（`--tab-provider-*`）で表すようにした。色だけに頼らないため `title` 属性（ツールチップ）と
`role="tab"` のアクセシブルネームにプロバイダ名を必ず添えているが、**この2つはどちらも
「常時可視」ではない**。

- ツールチップはホバーして初めて出る
- アクセシブルネームは支援技術（スクリーンリーダー等）を使っている人にしか届かない

結果として、**色覚特性を持つ晴眼のユーザー**（スクリーンリーダーを使わず、色相の差も
知覚しづらい）は、各タブをホバーするまでプロバイダを判別する手段が無い。
同じ `basename(cwd)` のタブが複数並ぶ状態（同一リポジトリで claude と gemini を
1本ずつ開く）で目的のタブを見分けるのに、ホバーという追加の手数が要る。

### 原因

Issue #20 が採用した設計そのものに内在する制約。解消しうる代案は両方とも却下済み。

- **先頭の文字マーク（`$` / `C` / `G`）** — Slack のワークスペースアバターの語彙であり、
  claude / codex がどちらも C、gemini / grok / goose がどれも G になって破綻する
- **タブ最小幅の拡大** — 8タブで横スクロールに落ち、状態表示面（B-3）が画面外に出て死ぬ

### 影響範囲

- `src/renderer/src/tabs/TabBar.tsx` / `src/renderer/src/styles.css` の `--tab-provider-*`

### 対処方針

- [ ] **解消しようとしない**（却下済みの2案以外に構造的な代案が無い）。
      `/design-review` の対象として残し、新たな代案が出た場合にのみ再検討する

### 優先度

P3

### ステータス

既知の制約として記録（解消しない前提）

## 7. スクリーンショット用の spec が make e2e の掃き出し対象から漏れる -> #90 として起票済み

### 症状

PR 9（#86）で `.tab-bar__tablist` を挟んだ際、`.tab-bar__tabs > .tab-bar__tab` という
直接子セレクタが壊れた。ワーカーは `e2e/specs/*.spec.ts` を全数 grep して7本を直したが、
**`e2e/screenshots.spec.ts` は `e2e/` 直下にあり glob から漏れていた**。

`make e2e` は `playwright.config.ts`、スクリーンショットは
`e2e/screenshots.playwright.config.ts` と**config が分かれている**ため、
`make e2e` は全 green のまま**壊れた状態が main にマージされた**。
`make e2e-screenshots` を回して初めて落ちる。

### 原因

- セレクタの掃き出し範囲を `e2e/specs/*.spec.ts` と考えてしまう（実際は `e2e/**/*.spec.ts`）
- `make check` にも `make e2e` にもスクリーンショットのレーンが含まれていない

### 対処方針

- [ ] セレクタを変える PR では `e2e/specs/` ではなく **`e2e/` 全体**を grep する
- [ ] `make e2e-lint` の check に「`e2e/screenshots.spec.ts` が参照するセレクタ」を
      加えられないか検討する（静的検査で拾えれば実行しなくても気づける）

### 優先度

P2

### ステータス

**PR 10（#88）で該当箇所を修正済み。** 再発防止の仕組みは未対処
