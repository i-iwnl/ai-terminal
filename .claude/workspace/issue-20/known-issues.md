## 1. cwd がアプリ起動時に固定され、複数リポジトリの並走が成立しない

### 症状

`src/renderer/src/lib/cwd.ts` は起動時に一度だけ `process.cwd()` を解決し、以後追跡しない。
シェルタブで別リポジトリに `cd` しても、AI タブは元のディレクトリで起動する。
Finder から `.app` を起動すると `process.cwd()` が `/` になり、**履歴タブが永久に空**になる。

### 原因（判明している場合）

起動時の解決値を共有 cwd として使い回す設計。

### 影響範囲

- `src/renderer/src/lib/cwd.ts` / `src/renderer/src/tabs/useTabs.ts`
- Issue #20 の B-1（行に `basename(task.cwd)` を出す）と I-2（スコープ行）の表示品質

### 対処方針

- [ ] **デザインより先に別 Issue で決着させる**（Issue #20 本文の「範囲外だが先に決着が要るもの」）
- [ ] 起票はユーザーの判断待ち

### 優先度

P1

### ステータス

未対処（未起票）

## 3. 余白の 4px グリッドに乗らない値が残っている

### 症状

PR 4 でトークンへの置換を終えたが、`styles.css` 本体には次のリテラルが残っている。

| 種類 | 残っている値 |
|---|---|
| 余白 | 2 / 3 / 6 / 10 / 14 / 18 / 20px |
| 角丸 | `border-radius: 4px`（`.terminal-search` のみ。尺は 2 / 3 / 6px） |

宣言した `--sp-6`（24px）と `--lh-tight` は、対応する使用箇所が現行に1つも無いため未参照のまま。

### 原因（判明している場合）

トークンを導入する前に書かれた値で、尺の設計なしに積み上がった。
**グリッドへ畳むと見た目が動く**ため、「置換」の PR（PR 3-4）には混ぜられない。

### 影響範囲

- 見た目への影響は今のところ無い（現状維持のため）
- PR 5 以降で余白の尺を動かしても、**これらの箇所だけ取り残される**

### 対処方針

- [ ] PR 5（値の変更）または密度・タイポグラフィの周（Issue #20 の H）で、グリッドへ畳むかを判断する
- [ ] 畳んだ結果 `--sp-6` / `--lh-tight` が使われなければ、その時点で宣言を削除する
      （`test/unit/css-tokens.test.ts` の許容リストからも外す）

### 優先度

P3

### ステータス

未対処（PR 5 で判断する。**放置しても壊れないが、尺を動かした瞬間にズレとして表面化する**）
