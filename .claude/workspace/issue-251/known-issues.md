## 1. #238 の PR 本文に、実装と合っていない `⛔ 次に触る人へ` が残っている

### 症状

PR #238 の本文が

> ⛔ `term.modes.mouseTrackingMode` を自前で見て早期 return しないこと

と、**本 Issue の修正そのものを禁止**している。理由として書かれている「xterm の wheel リスナーはマウス報告 ON なら何もせず return するので、カスタムハンドラにはそもそも来ない」が誤り。

### 原因

xterm.js 6.0.0 の wheel の経路が2本あることを見落としている。マウス報告 ON のときに走るのは `eventListeners.wheel -> sendEvent()` のほうで、こちらは `case 'wheel':` の冒頭でカスタムハンドラを呼ぶ。

### 影響範囲

- マージ済みの PR 本文は編集できるが、**同じ誤った説明が `useTerminal.ts` のコメントにも写っている**。コード側は本 Issue で訂正する。
- PR 本文そのものは履歴なので書き換えず、#251 からリンクして辿れるようにする。

### 対処方針
