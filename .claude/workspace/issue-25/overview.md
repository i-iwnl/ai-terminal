# Issue #25 設定を開いた直後のキー入力が PTY に流れる - Overview

> **Issue**: [#25 設定を開いた直後のキー入力が PTY に流れる（初期フォーカス・トラップ・復帰が無い）](https://github.com/i-iwnl/ai-terminal/issues/25)
>
> `role="dialog" aria-modal="true"` を宣言しながら、開いたときにダイアログ内へ
> フォーカスを移していなかった。`Cmd+,` で開いた直後にキーを打つと、その入力が
> **実行中の PTY に送られていた**。あわせて backdrop が `.main` の内側にあり、
> サイドバーが暗くならず操作もできる（モーダル契約の破綻）状態だった。
> 親 Issue [#20](https://github.com/i-iwnl/ai-terminal/issues/20) の Phase 0-e。
>
> **ユーザー判断で「独立ウィンドウにする」案を採用**（#20 の D と同じ方向）。
